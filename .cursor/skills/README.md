# Скиллы: Яндекс Игры (универсальные)

Набор для **разных** жанров и возрастов (0+ … 18+). Без привязки к конкретной игре.

## С чего начать

1. `yandex-games-bootstrap` — бриф, стек, карта скиллов  
2. `yandex-games-age-content` — возраст и запреты  
3. Дальше по задаче (таблица в bootstrap)

## Список

| Папка | Назначение |
|-------|------------|
| `yandex-games-bootstrap` | Старт проекта |
| `yandex-games-age-content` | 0+/6+/12+/16+/18+ |
| `yandex-games-sdk` | SDK + ads / saves / IAP / LB |
| `yandex-games-i18n` | п. 2.14 язык |
| `yandex-games-ui-layout` | Mobile/desktop вёрстка, типичные баги |
| `yandex-games-build-publish` | ZIP / Vite / vanilla |
| `yandex-games-draft-promo` | Черновик, скрины 9:16 и 16:9 |
| `yandex-games-test-debug` | Debug-панель, шум консоли |
| `yandex-games-moderation` | Чеклист перед отправкой |

Подключать в Cursor: Skills / правила проекта → путь к этой папке `skills/`.
