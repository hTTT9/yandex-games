# Черновик и промоматериалы

Доки: [черновик](https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft.md), [5.1.1.2](https://yandex.ru/dev/games/doc/ru/requirements/5/1/1/2.md), [5.1.3](https://yandex.ru/dev/games/doc/ru/requirements/5/1/3.md).

Возраст и категории — сначала `yandex-games-age-content`.

## Общее (не зависит от языка)

| Поле | Важно |
|------|--------|
| Архив | ZIP, `index.html` в корне, ≤100 МБ, латиница в путях |
| Платформы | Только реально поддерживаемые |
| Ориентация | Портрет / альбом / любая → заглушка SDK в другой |
| Языки | = реальные языки игры |
| Возраст / категории (≤2) / теги (≤20) | По контенту и рейтингу |
| Ключевые слова | lowercase, через запятую, ≤100 символов |
| Облачные сохранения | Вкл, если есть setData |
| Комментарий разработчика | ≤2048; SDK, cloud, ads, iap, LB |

## Тексты (на каждый язык)

| Поле | Лимит | Обязательность |
|------|--------|----------------|
| Название | ≤50, с заглавной, без КАПСа | * |
| SEO | 50–160 | рекомендуется |
| Об игре | 100–1000 | * |
| Короткое | ≤70 (уточнять в форме) | рекомендуется |
| Как играть | 100–1000 | * |

- Название уникально в каталоге (5.12) и **одинаково** в игре, текстах и на всех медиа этого языка (5.1.3).
- Не добивать лимиты пробелами/повторами; не копировать один текст в разные поля (5.11).
- RU+EN минимум для трафика; AI-описания консоли ≠ перевод UI.

## Медиа

| Материал | Типичный размер | Заметки |
|----------|-----------------|--------|
| Иконка | 512×512 PNG | Не скриншот (5.6) |
| Обложка | 800×470 PNG | Не скриншот |
| Maskable / витрина 1560×520 | опционально | |
| Скрины mobile | 9:16 (напр. 1080×1920, 720×1280) | |
| Скрины desktop | **ровно 16:9** (напр. 1920×1080, 1280×720) | |
| Видео | 9:16 / 16:9, до ~28 с | опционально |

### Скрины (5.1.1.2)

- Реальный геймплей (≥70% кадра) **или** качественное промо с игровым фоном.
- Не чужой геймплей и не одни и те же промо на разные игры.
- RU-медиа на вкладку Русский, EN — на Английский.

### Довести до 16:9 без обрезки UI

Если кадр уже́е (letterbox), вписать в 1920×1080 на фоне цвета UI игры (Pillow / любой редактор). Удобен режим съёмки из игры: `?shot=<screen>&layout=mobile|desktop`.

## Шаблон `promo/CHERNOVIK.txt` / `CONSOLE.txt`

В репо: общее → RU → EN → чеклист. Не класть в upload zip.

## Комментарий разработчика (тон)

Коротко: SDK/облако/реклама/инапы; игра будет дорабатываться; отзывы нужны. Без отсылок к другим своим тайтлам в каталоге.
