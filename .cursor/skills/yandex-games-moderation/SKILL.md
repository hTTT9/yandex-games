# Чеклист модерации Яндекс Игр

Полный список: [Требования к игре](https://yandex.ru/dev/games/doc/ru/concepts/requirements.md).  
Модерация обычно 3–5 рабочих дней. Дата в доке может обновляться — при сомнении сверять актуальный URL.

Перед чеклистом: возраст/контент (`yandex-games-age-content`), UI desktop/mobile (`yandex-games-ui-layout`).

## Техника (раздел 1) — критично

- [ ] 1.1 SDK встроен (`/sdk.js` + `YaGames.init`)
- [ ] 1.2 Только Яндекс ID; гостевой прогресс; авторизация по кнопке с выгодой
- [ ] 1.3 Звук стопается при потере фокуса
- [ ] 1.4 Платежи только через SDK
- [ ] 1.6 Соответствие заявленным платформам (mobile/desktop/TV)
  - Mobile: fullscreen, жесты, без системного плеера, без longtap-меню, ориентация = черновик
  - Desktop: активное поле до края **или** аккуратная центрированная оболочка; ratio ≤ 2:1; мышь без обязательной раскладки
  - TV: пульт стрелки+OK+Back, без инапов и ссылок на другие игры
- [ ] 1.9 Прогресс не теряется после F5 / поворота
- [ ] 1.10 Нет обрезки/наложений; нет браузерного скролла / swipe-to-refresh
- [ ] 1.11 Флаг облачных сохранений в черновике = факт использования setData
- [ ] 1.12 Монетизация: реклама и/или инапы (или комментарий модерации, если без)
- [ ] 1.13 Инапы: consume, валюта из SDK, cloud sync, цены, соответствие консоли
- [ ] 1.14 Нет крашей/зависаний на типовых действиях
- [ ] 1.15 Завершённый вид, не WIP
- [ ] 1.16 Не модифицировать/имитировать рекламные блоки
- [ ] 1.19 init + `LoadingAPI.ready` + корректные GameplayAPI / pause events
- [ ] 1.21 Размер ≤ 100 МБ распакованным
- [ ] 1.22 `index.html` в корне ZIP; пути без пробелов и кириллицы
- [ ] 1.23 Нет интерактивного ИИ в рантайме

## UX (раздел 2)

- [ ] 2.4 Есть игровые механики
- [ ] 2.6 Сохранение прогресса / рекорда
- [ ] 2.7 Возрастной рейтинг соответствует контенту и витрине
- [ ] 2.9 Основной контент > 10 минут
- [ ] 2.10 Локаль на заявленные языки
- [ ] 2.14 Автоопределение языка через SDK на старте

## Контент / реклама / промо

- [ ] 3.4–3.7 Запреты (политика, религия, эзотерика, насилие над детьми/животными, вывод реальных денег, азарт) — не нарушать
- [ ] 3.6 Не дубликат своей/чужой игры в каталоге (схема SDK ок, контент — нет)
- [ ] 4.1 / 4.4 / 4.5 / 4.7 Реклама только SDK, логические паузы, RV по кнопке, пауза звука
- [ ] 5.1.1.2 / 5.1.3 / 5.2 / 5.6 Скрины = геймплей; название одинаково; иконка/обложка ≠ скриншот; desktop 16:9

## Перед отправкой

1. `yandex-games-test-debug` + `yandex-games-draft-promo`.
2. ZIP через `yandex-games-build-publish`.
3. Комментарий разработчика: SDK / облако / реклама / инапы / LB.

При отказе: формулировка модерации → конкретный пункт доки → правка; не спорить без перепроверки.
