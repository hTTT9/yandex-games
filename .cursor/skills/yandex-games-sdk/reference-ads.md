# Реклама (adv)

Доки: [sdk-adv](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv.md), [расположение 4.4](https://yandex.ru/dev/games/doc/ru/requirements/4/4.md).

## Типы

| Метод | Назначение |
|--------|------------|
| `ysdk.adv.showFullscreenAdv({ callbacks })` | Interstitial между логическими паузами |
| `ysdk.adv.showRewardedVideo({ callbacks })` | RV по явной кнопке с понятной наградой |
| Sticky banner | Доп. блок; кастомные RTB запрещены (п. 4.6) |

## Когда показывать FS (п. 4.4)

- **Вне геймплея**: после неигрового действия (меню, «далее», магазин, рестарт) — сразу, задержка ≤ 0,33 с.
- **Пошаговые / короткие realtime (<5 мин)**: после действия / между уровнями; внутри короткого realtime-уровня — нельзя.
- **Длинный realtime (>5 мин)**: по таймеру + пауза + предупреждение ~2 с.
- После покупки «отключить рекламу» FS не показывать; RV обычно оставляют.

## RV (п. 4.5)

- Только по желанию игрока (кнопка).
- Текст/кнопка явно: будет реклама + что получит.
- Награда — бонус, не блокер основного прогресса.
- Начислять награду **только** в `onRewarded`, не в `onClose`.

## Обязательно при показе

1. `GameplayAPI.stop()`
2. Пауза звука и геймплея (п. 4.7)
3. В `onClose` / ошибке — resume + при нужде `GameplayAPI.start()`

```typescript
ysdk.adv.showRewardedVideo({
  callbacks: {
    onRewarded: () => { rewarded = true; },
    onClose: () => done(rewarded),
    onError: () => done(false),
  },
});
```

Частота FS — платформа; слишком частые вызовы → предупреждение в консоли.
