# Лидерборды (Leaderboards)

Доки: [sdk-leaderboards](https://yandex.ru/dev/games/doc/ru/sdk/sdk-leaderboards.md).

## Консоль

- Таблицу создать в консоли **до** вызовов из игры: техническое имя = строка в коде.
- В **черновике** без таблицы API часто отвечает **404** — это не краш клиента, а отсутствие ресурса.

## Код

- `setScore` / `getEntries` (или legacy `getLeaderboards`) — только после init.
- Оборачивать в `try/catch`; при 404 / `LEADERBOARD_NOT_FOUND` / «not found» — **тихо** отключить LB на сессию (`lbOff`), не спамить `console.error`.
- Не считать unhandled rejection нормальным UX: await + catch; снаружи SDK всё равно может логировать своё — главное не ронять игру.

## UX

- Показ топа — опциональный блок; при недоступности LB показывать пусто / локальный демо-топ, не блокировать прогресс.
- Не слать score каждый кадр; после осмысленного события (конец уровня, новый рекорд).
