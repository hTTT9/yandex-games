# Сохранения (Player + local)

Доки: [1.9](https://yandex.ru/dev/games/doc/ru/requirements/1/9.md), [sdk-player](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player.md).

## Правила

- Прогресс сохранять сразу после действия или по явной кнопке; после F5 / поворота экрана не терять (п. 1.9).
- Гостевой вход обязателен: игра без авторизации с сохранением прогресса (п. 1.2.2).
- Облако: `player.setData` / `getData` (и при необходимости `setStats`). В черновике включить «Игра использует облачные сохранения» (п. 1.11).
- Покупки и прогресс карьеры — на сервере Яндекса, доступны с разных устройств (п. 1.13.3).
- `flush: true` при критичных моментах (скрытие вкладки, выход в меню, покупка).

## Паттерн

1. Локальный кэш: `localStorage` + `parseSavePayload` с миграциями и отсечением `{ cleared: true }`.
2. Cloud: один ключ (например `save`) внутри `setData({ save: payload }, flush)`.
3. При старте: загрузить cloud и local, взять более свежий по `updatedAt`.
4. Авторизация только по кнопке с понятной выгодой (п. 1.2.1); без сторонних логинов (п. 1.2).

```typescript
await player.setData({ save: payload }, flush);
const data = await player.getData(['save']);
```

Лимиты методов — в доке Player; не спамить setData в каждом кадре.
