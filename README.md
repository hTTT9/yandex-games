# Тихая заводь (Quiet Cove)

Казуальная рыбалка для **Яндекс Игр** · hiThere games · 6+ · v0.2.0.0

## Локальный запуск

```bash
python3 -m http.server 8877 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8877/ (нужен HTTP из‑за ES modules). Без `/sdk.js` подключается mock YaGames.

Съёмка: `?shot=pier|menu|catch|journal|shop&layout=mobile|desktop`

## Архив для консоли

`dist/quiet-cove.zip` — только `index.html`, `css/`, `js/`, `assets/`.

Тексты черновика: `promo/CONSOLE.txt` (не в ZIP).
